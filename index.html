if wallHit and wallJumpsLeft > 0 then

    wallJumpsLeft -= 1

Sprint, crouch, slide, slide-jump, and up to 3 consecutive wall jumps before landing. Movement runs through a state machine so none of these ever conflict. The katana adds passive bonuses on top: 15% speed, 20% jump height, double wall-jump force.

Dual-Wield Weapon System

-- two independent hand slots
local hands = {
    left  = Hand.new(),
    right = Hand.new()
}

-- walk over weapon → fills next open slot
function pickUp(weaponDef)
    local slot = hands.right.empty
        and "right" or "left"
    hands[slot]:equip(weaponDef)
end

-- mag runs dry → auto-drop
if hand.ammo <= 0 then
    dropWeapon(hand); hand:clear()
end

Left and right hand slots managed independently. One-handers stack — LMB fires right, RMB fires left. Two-handers (rifles, launchers) claim both slots. Each hand tracks its own mag and auto-drops on empty. Weapon positioning handled via RigidConstraint + IKControl on the off-hand grip.

05

Main Menu — UI State Machine

-- 5 decoupled controllers via event bus
-- Nav → Page → Lobby/Settings/Shop
function PageController:Open(id)
    if self._current == id
        then return end
    self:_close(self._current)
    self._current = id
    self:_open(id)
end

NavList.onSelect:Connect(function(id)
    PageController:Open(id)
end)

Five controllers (NavList, Page, Lobby, Settings, Shop) talk through an event bus — no direct references between them. Each page owns its open/close lifecycle. Adding a new screen means writing one controller, not touching the others.

Match System & Elo Ranking

-- standard Elo formula
local function expected(rA, rB)
    return 1/(1 + 10^((rB-rA)/400))
end
local delta = K * (score - expected(rA,rB))

-- MatchManager: Waiting → Active → Ended
function Match:_onEliminated(p)
    if #self:_alive() == 1 then
        self:_end()
    end
end

MatchManager cycles Waiting → Active → Ended. On end, Elo deltas are calculated for all participants and persisted to DataStore. FFA, 1v1 Duel, and 2v2 Wingman all share the same base Match class with a different scoring hook per mode.
